# VouchNet 1.6.0 — Desktop expansion

Ship date: 2026-10-28 (America/New_York).

## Highlights

- **Native Network** on Desktop: contacts, invitations, and mutual-context recommendations.
- **Jobs / Organizations** load from authenticated Desktop directory APIs with search.
- **Opportunities** and **Saved** join the rail; Ctrl+K searches people, jobs, and companies.
- **Security**: CSP upgrade-insecure-requests, tighter Desktop CSP, `desktopRead` rate limits,
  expanded Permissions-Policy denials.

## Desktop API surface

| Route                                | Purpose                       |
| ------------------------------------ | ----------------------------- |
| `GET /api/desktop/network`           | Overview + recommendations    |
| `POST /api/desktop/network/connect`  | Request / accept / decline    |
| `GET /api/desktop/search?q=`         | People + jobs + organizations |
| `GET /api/desktop/jobs`              | Salary-forward directory      |
| `GET /api/desktop/opportunities`     | Open work briefs              |
| `GET/POST/DELETE /api/desktop/saved` | Saved posts                   |

## Installers

Windows NSIS/MSI and SHA-256 checksums publish through the GitHub Release workflow for tag
`v1.6.0` when that tag is pushed.
