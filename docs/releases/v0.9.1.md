# VouchNet v0.9.1 — Stability patch

**Release date:** 2026-10-01
**Distribution:** Source only — no binaries, installers, archives, or hosted artifacts are included.

## What changed

- Authenticated navigation now combines daily-game notification materialization and unread-badge
  calculation in a single database lifecycle.
- Feed failure messages clear after recovery, reactions close their picker after selection, and the
  protected shell includes a keyboard skip link.
- Browser telemetry deduplicates repeated errors for 30 seconds. Its intake, plus follow, unfollow,
  and block mutations, are protected by the existing distributed rate-limit policy.
- Follow and block route identifiers are strictly validated as UUIDs before the social graph is
  changed.

## Verification

The source tree was checked with:

```text
pnpm typecheck
pnpm lint
pnpm test
pnpm format:check
pnpm build
```

## Deployment notes

- Apply database migrations through `0021` before deploying features introduced in v0.9.0.
- Production abuse controls require a reachable `REDIS_URL`; protected mutations fail closed when
  that dependency is unavailable.
- This release does not add a database migration.
