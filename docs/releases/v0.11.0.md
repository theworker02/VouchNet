# VouchNet 0.11.0 — Desktop foundation

Released October 4, 2026.

## Included

- VouchNet Desktop 1.0.0 source: Tauri 2, Rust, and React with a native desktop shell.
- Shared-service desktop authorization using browser PKCE, one-time codes, deep links, and rotating
  device refresh credentials.
- The first real shared message model and web surface: accepted-contact access, blocking checks,
  read receipts, safe HTTPS attachment records, and unread state.
- Canonical VouchNet desktop icon generation and Windows NSIS/MSI bundle configuration.
- Website Download and Releases surfaces.

## Before production deployment

1. Apply PostgreSQL migrations through `0027`.
2. Generate and protect a Tauri updater signing key, configure a hosted update manifest, and attach
   signed NSIS/MSI artifacts plus SHA-256 values to the GitHub release.
3. Build the Windows bundles on a release runner and code-sign them before publishing. The source
   repository does not contain signing credentials.
4. Configure the `vouchnet://` protocol with the released installer, then verify browser sign-in
   returns to the foreground desktop app.

## Known limits

- Desktop 1.0.0 establishes the native shell, secure account boundary, and shared feed. Dedicated
  native views for the full message editor, organization administrator tools, tray behavior,
  updater delivery, and native notification actions require their remaining service APIs and signed
  release infrastructure; this release does not pretend they are available.
- Message attachments are currently explicit HTTPS URLs. Server-side upload/presigned object storage
  has not been added, so the UI does not claim local file upload is complete.
