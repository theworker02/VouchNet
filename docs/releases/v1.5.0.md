# VouchNet 1.5.0 — Desktop Signal Desk

Released October 28, 2026.

## Included

- Native desktop activity inbox backed by the same member notifications as the web app, including
  mark-as-read over the device Bearer token.
- Home feed discovery panels for the daily Signal Circuit challenge, skill topics, and
  salary-forward roles already returned by `/api/desktop/feed`.
- First-class Jobs and Organizations workspace surfaces that render curated directory records
  instead of only opening the browser.
- Discover in the desktop rail and command palette, with letter-key shortcuts across every space.
- Working conversation search, unread activity badges, and optional Windows notifications when new
  unread messages arrive.
- Shared design tokens, reduced-motion support, and a calmer desktop shell aligned with the
  VouchNet interface system.

## Download integrity

The release publishes `VouchNetSetup-1.5.0-x64.exe`, `VouchNet-1.5.0-x64.msi`, and
`VouchNet-1.5.0-x64.sha256` through the GitHub Release workflow. Verify the SHA-256 values before
installing.

The installer is not code-signed in this release. Windows may show a publisher or SmartScreen
warning. Do not bypass a warning unless the downloaded file matches the official checksum.
