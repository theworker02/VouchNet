# VouchNet v0.9.5 — Security workflow repair

## Summary

This source-only patch restores a meaningful, passing Security workflow without suppressing an
unpatchable development-tool advisory as though it affected the deployed application.

## Included changes

- The runtime dependency gate now installs the lockfile-pinned production graph with lifecycle
  scripts disabled and fails on high-or-higher production advisories.
- CodeQL remains enabled for JavaScript/TypeScript analysis on protected branch pushes.
- GitHub Dependency Review remains required for dependency changes introduced through pull
  requests, including development dependencies.
- The current unpatchable development-only `braces` advisory and its compensating controls are
  documented in the security architecture.

## Verification

```powershell
pnpm install --frozen-lockfile --prod --ignore-scripts
pnpm audit --prod --audit-level=high
pnpm typecheck
pnpm lint
pnpm test
pnpm build
```

## Distribution

No binaries, installers, or compiled artifacts are attached to this release.
