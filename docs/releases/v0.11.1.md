# VouchNet 0.11.1 — Public Preview Polish

Released October 4, 2026.

## Included

- A GitHub README gallery with current desktop landing, mobile landing, and sign-in screenshots.
- Better-balanced landing hero typography alongside the product workspace preview.
- A mobile-safe fixed feedback action that remains clear of browser and device safe areas.
- A quieter local development surface: the Next.js inspector no longer overlaps the VouchNet UI.

## Release contents

This is a source-only release. It contains no database migration, signed Desktop installer, updater
artifact, checksum, or binary download. Existing production deployments do not need a database
change for this release.

## Known limits

VouchNet Desktop installation and automatic updates remain unavailable until signed Windows
artifacts, checksums, and update infrastructure are published. The screenshots document the current
web surface; they are not a substitute for accessibility and browser testing across supported devices.
