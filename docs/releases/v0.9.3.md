# VouchNet v0.9.3 — Faster, bounded authenticated navigation

## Summary

This source-only patch improves the resilience of the authenticated feed and removes avoidable
database work from normal page rendering.

## Included changes

- A profile lookup is shared by the shell and route content during one React server render.
- The initial feed response is bounded to 40 eligible posts so its aggregate calculations remain
  predictable as a member's network grows.
- Feed requests abort after eight seconds and expose a retry control if a dependency is delayed or
  unavailable.
