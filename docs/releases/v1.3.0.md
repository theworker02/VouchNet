# VouchNet 1.3.0 — Responsive Public Surface

Released October 4, 2026.

## Included

- Keyboard-accessible compact public navigation on narrow displays, retaining direct links to core
  public VouchNet surfaces when the desktop link row is hidden.
- A public `/releases/1.3.0` page and updated release index for the current platform source
  release.
- The public-preview polish introduced in 0.11.1: current README screenshots, balanced landing
  typography, mobile-safe feedback placement, and a non-overlapping local development surface.

## Release contents

VouchNet 1.3.0 is a source-only release. It contains no database migration, signed Desktop
installer, updater artifact, checksum, or binary download. The 1.0.0 Desktop source remains a
foundation release; signing, update delivery, and installer publishing must be completed before
Desktop binaries are presented to members.
