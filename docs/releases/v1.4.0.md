# VouchNet 1.4.0 — Desktop Distribution & Public Discovery

Released October 13, 2026.

## Included

- VouchNet Desktop 1.4.0 for Windows x64, shipped as both an NSIS setup executable and an MSI.
- Identical VouchNet mark assets for the Windows application, taskbar, installer, and package icon.
- Public, checksum-addressable installer downloads at `vouchnet.dev/download/windows`.
- A GitHub Actions release workflow that builds Windows installers, emits SHA-256 checksums, uploads
  artifacts, and attaches them to the version tag.
- A landing-page discovery preview driven by existing reviewed organizations and transparent roles,
  not invented members or engagement.
- JSON-LD `ItemList` data for the jobs directory and `JobPosting` data for individual source-linked
  role pages.

## Search visibility

The verified `vouchnet.dev` Google Search Console property has a successful sitemap submission:
`https://vouchnet.dev/sitemap.xml`. At the time of this release Google reports 42 discovered URLs,
7 indexed URLs, and 31 pages in its normal “Discovered — currently not indexed” queue. This release
improves crawlable public content and structured data; indexing remains Google’s decision and can
take time for a new site.

## Download integrity

The release publishes `VouchNetSetup-1.4.0-x64.exe`, `VouchNet-1.4.0-x64.msi`, and
`VouchNet-1.4.0-x64.sha256`. Verify the SHA-256 values before installing.

The installer is not code-signed in this release. Windows may show a publisher or SmartScreen
warning. Do not bypass a warning unless the downloaded file matches the official checksum.
