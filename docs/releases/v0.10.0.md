# VouchNet v0.10.0 — Experiences runtime and Labs

## Summary

This source-only minor release introduces the first security-first VouchNet Experiences runtime:
interactive HTML, CSS, and JavaScript published as feed posts without executing in the VouchNet
application context. It also introduces an optional browser-local Labs space for safe presentation
experiments and local runtime diagnostics.

## Included changes

- Added `INTERACTIVE` post persistence with bounded source fields, an explicit Runtime 1.0 manifest,
  and an `ACTIVE`/`DISABLED` execution state.
- Added `/feed/create`, source tabs, a hot-reloading preview, and the original `Open to connect`
  template.
- Each published Experience renders in an opaque-origin iframe with `sandbox="allow-scripts"` and
  an internal restrictive CSP. It has no network, VouchNet SDK, storage, form submission, popup,
  download, navigation, worker, or device access.
- Added VouchNet Labs, unlocked locally by typing `vouch` outside editable fields. Its preferences
  remain only in the current browser and never grant server-side authority.
- Added a loopback-only local endpoint measurement tool and optional short local Ollama request.
  It rejects remote/credentialed URLs, disables redirects, does not scan, and does not send results
  through VouchNet.

## Required deployment step

Apply database migration `0025_interactive_post_experiences` before enabling this release in an
environment that allows interactive publishing:

```powershell
pnpm db:migrate
```

The migration must be reviewed and applied against the intended PostgreSQL environment. It is not
automatically applied by the release process.

## Verification

```powershell
pnpm typecheck
pnpm lint
pnpm test
pnpm format:check
pnpm build
```

## Explicitly not included

- No `postMessage`/RPC VouchNet SDK or social-action capabilities.
- No controlled external networking, shared/viewer state, submitted-form persistence, analytics,
  or visual block builder.
- No remote endpoint scanner, browser credential access, or hidden administrator functionality.

## Distribution

No binaries, installers, or compiled artifacts are attached to this release.
