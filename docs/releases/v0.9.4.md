# VouchNet v0.9.4 — Honest first-feed density

## Summary

This source-only release makes a new member's first feed useful without simulating a populated
social graph. VouchNet uses existing source-reviewed public organizations and job listings, paired
with its original daily strategy challenge, until the member has eligible human-authored posts.

## Included changes

- The feed API returns a compact discovery snapshot alongside eligible member posts.
- Empty feeds now show real, source-reviewed job and organization records with direct VouchNet
  directory links and visible provenance.
- The daily challenge remains available if the public directory is temporarily unavailable.
- Discovery data is limited to small, bounded collections to preserve the fast initial feed path.

## Integrity policy

- No fake users, fabricated employment, automated social accounts, fake posts, or fake reactions
  were introduced.
- New member activity stays empty until real human members create it; the fallback is clearly
  separated from member activity.

## Verification

Run from the repository root:

```powershell
pnpm format:check
pnpm typecheck
pnpm lint
pnpm test
pnpm build
```

## Distribution

No binaries, installers, or compiled artifacts are attached to this release.
