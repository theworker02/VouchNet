# Projects

Projects are first-class owned records with their own slug, visibility, URLs, status, and future extension points for contributors and releases. They are not profile text blobs.

Build in Public adds followers, invited contributors, dated build logs, an open-source flag, a
"looking for" list, and the statuses Idea, Active development, Launched, Maintained, and Archived.
Legacy `ACTIVE` and `SHIPPED` rows are read as Active development and Launched. See
[Build in Public](BUILD_IN_PUBLIC.md).
